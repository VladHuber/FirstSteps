# FirstSteps

Первые шаги в Rust: девять учебных заданий — независимых крейтов (`task1` … `task9`).
Каждое задание лежит в своей папке со своим `Cargo.toml`, поэтому открыть любой файл можно прямо на GitHub.

Все папки — обычные каталоги репозитория (не сабмодули): раньше каждая задача была отдельным
репозиторием `VladHuber/task1` … `VladHuber/task9`, теперь они собраны в один родительский репозиторий —
по той же схеме, что и [Mini-project](../Mini-project).

## Требования

- Rust **1.85+** (во всех крейтах `edition = "2024"`)
- Стабильный тулчейн: https://rustup.rs

## Как запускать

Каждое задание — отдельный проект, поэтому команды выполняются из его папки:

```bash
cd task1
cargo run
```

Задания интерактивные: они читают ввод с клавиатуры, поэтому запускать их нужно в терминале.
Для остановки цикла ввода в большинстве заданий используется буква `x` или `Ctrl+C`.

## Заметки по коду

- Задания учебные: местами есть `unwrap()`, закомментированный код и неиспользуемые импорты,
  поэтому `cargo run` может показывать предупреждения компилятора — это нормально.
- `task4` пока использует жёстко заданное значение `chance_rng = 99` (генератор случайных чисел закомментирован),
  то есть всегда выпадает легендарный предмет — удобно для отладки `match`.
- `task5` подключает `crossterm`, но очистка экрана в коде закомментирована; анимация работает на стандартных
  `print!` + `flush()`.
- `task2` печатает результат в отладочном формате `{:?}` — список выглядит как `["дело1", "дело2"]`.
- Сборка (`target/`) каждого крейта игнорируется и не коммитится: `cargo build` / `cargo run` выполняются локально.
